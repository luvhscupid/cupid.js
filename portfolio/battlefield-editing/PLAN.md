# Execution Plan

Keep this to one portfolio sample. Do not start an automated editing pipeline or add dependencies.

## Stage 1 — Local inspection

Local Codex should inspect the 74 inventoried video files, verify game/content and usable moments, note candidate source filenames and time ranges locally, and check FFmpeg availability. Inventory counts do not establish what the footage contains. Keep detailed source paths and any contact sheets on the PC.

## Stage 2 — Select and shape

After inspection, identify a small set of strong, complementary moments for a 25–35 second arc. Agree on an opening, progression, and ending based on the actual material. Cloud Codex can help refine the sequence from Local's written descriptions; it does not need access to the media.

## Stage 3 — Edit in Premiere Pro

Local Codex assembles the selected moments in Premiere Pro, trims for clear action and pacing, balances audio, and adds only restrained polish that supports the footage. Keep the editable project and all media on the PC.

## Stage 4 — Export and verify

Export a client-facing sample, play it through locally, confirm duration is 25–35 seconds, inspect picture and audio for obvious defects, and record the actual export properties and verification evidence in `CHECKPOINT.md`. Keep the export local.

## Handoff boundaries

Cloud Codex owns this plan and Git-tracked notes. Windows Local Codex owns media inspection, clip selection, Premiere Pro editing, and export verification. Exchange findings as concise written notes in the checkpoint; do not sync media or machine-specific paths through Git.
