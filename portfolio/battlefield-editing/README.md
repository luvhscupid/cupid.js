# Battlefield 6 Highlight Portfolio Project

## Goal

Produce one polished 25–35 second Battlefield 6 highlight that demonstrates short-form editing skill to prospective paid clients. The footage has not been visually reviewed, so no clips, moments, or edit decisions are selected yet.

## Cloud Codex

- Maintain the brief, plan, acceptance criteria, and checkpoint in this folder.
- Help shape a concise creative direction after Local Codex reports what the footage actually contains.
- Track decisions and review notes from evidence supplied by Local Codex.
- Do not claim footage analysis, editing, or export verification.

## Windows Local Codex

- Inspect the inventoried footage on the user's PC and verify what it contains.
- Check whether FFmpeg is available; do not install dependencies for this project.
- Select suitable moments, edit the sample in Premiere Pro, export it, and verify the exported file locally.
- Keep source footage, contact sheets, project media, and exports on the PC. Do not add them or local machine paths to Git.
- Record only concise findings, decisions, and verification evidence in the checkpoint.

## Acceptance criteria

- Final sample is 25–35 seconds and uses verified Battlefield 6 footage.
- The edit has a clear opening, coherent sequence of highlights, deliberate pacing, and a clean ending suitable for showing prospective clients.
- Picture and audio are intentional, with no unintended black frames, gaps, or clipping.
- Export plays through locally and its duration and basic output properties are recorded in `CHECKPOINT.md`.
- Git contains only project documentation; no raw media, contact sheets, exports, or PC-specific paths.

## Documents

- `PLAN.md` — small, staged execution plan and handoff.
- `CHECKPOINT.md` — current state, evidence, blockers, and exact next action.
