# Cupid’s Corner

A playful, interactive little home for Cupid’s reminders about self-love, kindness, and sharing care with other people.

## Run locally

```powershell
pnpm install
pnpm dev
```

Vite prints the local preview address. Build the production version with:

```powershell
pnpm run build
```

## What’s inside

- Short interactive moments: the Love Compass, love-style quiz, kindness prompt, growing garden, Love Ripple, heart hunt, and personal notes.
- The garden and note to Future You are stored in this browser only. They are not sent to a server.
- Motion effects respect the system reduced-motion preference.

## Stack

React, TypeScript, Vite, GSAP, Lenis, Tailwind CSS, and lucide-react.
